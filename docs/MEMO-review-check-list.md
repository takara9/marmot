# レビュー受け入れ/却下チェックリスト（5項目）

**レビュー判定チェックリスト**
1. この指摘は、今回PRの目的機能に直接関係しているか  
2. バグ・仕様回帰・セキュリティ・テスト欠落のいずれかに該当するか  
3. 再現手順または失敗条件を示せるか  
4. 変更の影響範囲を説明できるか（副作用を含む）  
5. 重要度がHigh以上か（運用ルール基準）

**判定ルール**
1. 1〜5をすべて満たす: このPRで対応  
2. 1または2を満たさない: 今回は却下（目的外）  
3. 3を満たさない: 追加情報依頼（保留）  
4. 4を満たさない: 影響調査後に再判定  
5. 5を満たさない: 別PR候補または見送り

**レビュー返信テンプレート**
1. 受け入れ  
ご指摘ありがとうございます。PR目的に直結し、再現可能な不具合のため、このPRで修正します。

2. 目的外で却下  
ご提案ありがとうございます。今回はPR目的外のため対応範囲外とし、必要であれば別PRで扱います。

3. 情報不足で保留  
ご指摘ありがとうございます。再現条件（入力値・手順・期待結果）をご共有いただければ、対応可否を再判定します。

4. 低優先度で別PR  
ご提案ありがとうございます。改善余地はありますが、重要度がHigh未満のため今回PRでは見送り、別途チケット化します。

必要なら次に、これをそのまま貼れる短縮版（PRテンプレ用10行）も作成します。
